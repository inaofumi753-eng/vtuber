# VTuber Bot

Local Twitch bot + lightweight VTuber for Windows.

Target: Ryzen 5 5600G, 16 GB RAM and OBS Studio.

Status: V0.1 Foundation.

Planned systems: commands, points, rankings, giveaways, minigames, moderation, automatic messages, PNG/2.5D avatar, local voice, desktop control panel, Telegram Web interface, OBS integration, performance monitoring and SQLite.

The final product does not depend on AI APIs. GPT and Gemini are development tools.
